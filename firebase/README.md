# Fichiers Firebase

- [`firestore.rules`](firestore.rules) — les règles de sécurité à coller dans
  la console Firebase (étape 4 de [`../FIREBASE.md`](../FIREBASE.md)).

**Rien dans ce dossier ne contient de données réelles ni de secret.**
La configuration Firebase (clé publique, identifiant de projet) sera ajoutée
plus tard ; malgré son nom, la clé `apiKey` de Firebase n'est pas un mot de
passe et peut figurer dans un dépôt public. Ce qui protège les données, ce sont
les règles ci-dessus et le mot de passe du compte.
