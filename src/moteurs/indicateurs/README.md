# Indicateurs

**Lot 5 puis priorité 2** (cahier des charges §9.4, §14).

Ce dossier accueillera le calcul des indicateurs : couverture, sureffectif,
conformité, équité, heures prévues face aux contrats et au budget,
productivité, absentéisme, polyvalence.

**Règle d'architecture** : code pur. Les indicateurs sont calculés ici, puis
seulement affichés par l'interface ou repris dans les PDF.
